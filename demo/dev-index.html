Comandi utili

Docker · psql · redis-cli
🐳 Docker Compose
docker compose up -d # avvia docker compose down # stop docker compose logs -f web # log live docker compose ps # status docker restart neogesys-web # riavvia solo web
🐘 PostgreSQL
docker exec -it neogesys-postgres \ psql -U neogesys -d neogesys_sport # da host: psql postgresql://neogesys:neogesys_dev@localhost:5433/neogesys_sport

docker exec -it neogesys-redis redis-cli > KEYS * > FLUSHDB
